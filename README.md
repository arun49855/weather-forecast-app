# Weather App

A simple responsive weather dashboard built with HTML, CSS and JavaScript.

## Features
- Search a city
- Shows weather details using Open-Meteo's public geocoding and forecast APIs
- Displays current temperature, wind speed, and weather conditions
- Shows a 5-day forecast
- Responsive layout for desktop and mobile

## How to run
1. Extract this ZIP file.
2. Open `index.html` in a modern browser with internet access.
3. Enter a city name and click **Search**.

## Technologies
- HTML
- CSS
- JavaScript
- Open-Meteo API (no API key required for this demo)

## Notes
Weather results require an internet connection. Forecasts can differ from conditions at your exact location. This is a student demo, not an emergency weather service.
